# ShopMind 🛍️

### AI-Powered Intelligent Shopping Assistant

ShopMind is an AI-powered personalized shopping assistant designed to help users discover, compare, and select products through natural-language conversations.

Instead of manually browsing hundreds of products, users can describe their requirements, budget, and preferences. ShopMind analyzes these requirements and recommends suitable products.

## Features

- Intelligent product search
- Personalized product recommendations
- Budget-based filtering
- Product comparison
- AI-powered shopping assistant
- Customer review analysis
- User preference management
- Multi-agent recommendation architecture

## Technology Stack

| Technology | Purpose |
|---|---|
| Python | Core programming language |
| Streamlit | User interface |
| FastAPI | Backend API |
| SQLite | Product database |
| Pandas | Data processing |
| Scikit-learn | Recommendation algorithms |
| Sentence Transformers | Semantic search |
| LLM API | Conversational AI |

## Project Architecture

ShopMind follows a modular architecture consisting of:

- Product Search Engine
- Recommendation Engine
- User Preference Manager
- AI Shopping Agents
- Product Comparison System
- SQLite Database
